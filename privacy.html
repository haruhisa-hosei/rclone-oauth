Privacy Policy

Last updated: 2026-10-06

rclone-home is an OAuth client used only by its owner to run rclone on the owner's own computers.

  • It accesses Google Drive only to copy and synchronise the owner's own files to and from the owner's own Google Drive.
  • Google user data accessed through this client is used solely for that purpose. It is not shared with, sold to, or transferred to any third party, and it is not used for advertising or analytics.
  • OAuth tokens are stored only in the rclone configuration on the owner's own computers. No data is sent to any server operated by this client.
  • Access can be revoked at any time from the Google Account permissions page.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
